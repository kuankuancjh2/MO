# 莫 · MO

> 你就是一个「莫」字。你踩过的一切都会化为虚无——
> 用这份「没有」闯过不断崩塌的世界，捡起偏旁，把自己拼成新的字。

Godot 4.7 横版闯关 + 平台动作 + 轻肉鸽。GameJam 原型。

`莫` = 一个空。下面填「心」就是**慕**，填「日」就是**暮**，填「氵」就是**漠**。
踩过的方块 4 秒后会消失；失足掉落不会死，只会掉到下一层继续打。

---

## 快速开始

```bash
# 打开编辑器（Godot 可执行文件就在 Tools/ 里）
Tools/Godot.exe

# 或直接命令行跑一局（4 秒后自动退出）
Tools/Godot_console.exe --path . --quit-after 240

# 跑回归测试（自动操作主角、验证 23 项机制、自动截图）
Tools/Godot_console.exe --path . res://devtools/smoke_test.tscn
```

## 操作

| 键 | 动作 |
|---|---|
| `A` / `D` 或 `←` / `→` | 移动 |
| `空格` / `W` / `↑` / `Z` | 跳跃 |
| `J` / `X` / 鼠标左键 | 攻击（墨点） |
| `Q` / `E` | 主动技能（携带对应偏旁时） |
| `R` | 重开一局 |

## 玩法要点

- **踩过的方块 4 秒后消失**，颜色会先变黄、再变红、闪得越来越快 —— 学会读它还剩多久。
- **捡偏旁变身**：心→慕（磁吸金币）、日→暮（地面消失变慢，但天会黑）、
  氵→漠（按 Q 喷水柱）、土→墓（踩过的方块不再消失，但变重）、月→膜（减伤）、饣→馍（回血）。
- **每个字都有代价**，这是本作的取舍乐趣所在。
- **掉落不会死**，掉到下一层接着打；只有掉太远才会扣一点血（单次最多 1.5 心，且永远留 1 心）。
- 打红色方块怪掉金币；死亡结算成魂币（存 `user://mo_save.json`）。

## 换美术（不改代码）

改一个文件就行：`assets/config/asset_config.tres` —— 字体、所有元素的颜色、方块贴图。
详见技术文档第 8 章。

## 目录速览

```
assets/config/asset_config.tres   # ★ 美术唯一入口
data/balance.tres                 # 手感/平衡数值
data/radicals/*.tres              # 每个偏旁一个字一个文件（纯数据，改完即生效）
scenes/main/main.tscn             # 唯一的场景文件
scripts/                          # 全部逻辑（节点结构在代码里搭）
devtools/                         # 资源生成器 + 回归测试
```
