# 莫 · MO

> 你就是一个「莫」字。你踩过的一切都会化为虚无。
> 踩碎的地里会浮出偏旁 —— 把它们拼成新的字，闯过一座又一座正在崩塌的岛。

Godot 4.7 横版闯关（岛屿地图）+ 平台动作 + 轻肉鸽。GameJam 原型。

`莫` = 一个空。填「心」就是**慕**，填「日」就是**暮**，填「氵」就是**漠**。

---

## 快速开始

```bash
Tools/Godot.exe                                            # 编辑器，F5 玩
Tools/Godot_console.exe --path . res://devtools/smoke_test.tscn   # 回归测试（60 项）
Tools/Godot_console.exe --path . res://devtools/shot.tscn         # 取截图
```

## 操作

| 键 | 动作 |
|---|---|
| `A`/`D` 或 `←`/`→` | 移动 |
| `空格`/`W`/`↑` | 跳跃（落地前按下可**卸力免伤**；拿到「蟆」后空中再按一次 = 二段跳） |
| **鼠标左键** | 攻击（墨点朝鼠标方向射） |
| `Q` / `E` | 主动技能 |
| `F` | 与商店交互 |
| `R` | 重开一局 |

## 玩法要点

- **踩过的方块 2.6 秒后碎掉**（先变黄 → 变红闪得越来越快 → 消散）。读得出来还剩多久。
- **偏旁埋在地面方块里**：碎开的一瞬间字会浮出来，然后自己飞向你。
- **踩到怪头上不是踩死它 —— 而是骑着它走**：不杀、不掉血，它往哪走你就到哪，
  控制不了（想下来就跳走）。怪既是威胁也是交通工具。
- **每个字都有代价**（暮让你看得见但天变黑，墓让地面不消失但你变慢…）。
- **同时带特定几个字会出组合技**（心+日 = 暮慕：黑暗中吸来的东西会发光）。
- **掉落不会死**：<4.5 格没事；4.5~10 格扣 1 心但落地前按跳跃可卸力；太高就卸不掉。
- **Boss「有」** 在「有之殿」里 —— 莫是"无"，有是"有"，它不停地造东西，你把它抹掉。
- 打怪掉金币，进小屋/集市按 F 买东西（**买的时候时间不停，你脚下还在塌**）。

## 换美术 / 换音效（都不用改代码）

```
assets/art/     ← 丢图，用固定文件名（player.png / tile_rock.png / enemy_flyer.png …）
assets/audio/   ← 丢音频，用固定文件名（jump / vanish / shatter / coin …）
assets/config/asset_config.tres   ← 只改配色/字体
```

清单见 `docs/美术资源指南.md` 与 `assets/audio/README.md`。

## 目录速览

```
assets/art/  assets/audio/  assets/config/asset_config.tres   # 美术音频配色
data/balance.tres          # 手感数值（消失时间、跳跃、掉落伤害…）
data/radicals/*.tres       # 11 个字（纯数据，改完即生效）
data/structures/*.tres     # 8 个结构（字符网格，像 MC）
scenes/main/main.tscn      # 唯一的场景文件
scripts/                   # 全部逻辑（节点结构在代码里搭）
devtools/                  # 资源生成器 + 回归测试 + 截图工具
```
