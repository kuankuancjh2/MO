# 《莫》游戏设计文档（GDD）

> 引擎：Godot 4.7 · 类型：横向闯关 + 平台动作 + 轻肉鸽
> 状态：✔ 已实现 ○ 待做

---

## 1. 一句话概念

你就是一个「莫」字。你踩过的一切都会化为虚无——用这份「没有」闯过崩塌的世界，
敲碎字块，把自己拼成新的字。

`莫` = 一个空。填「心」是**慕**，填「日」是**暮**，填「氵」是**漠**。

> **无中生有。**

---

## 2. 核心循环

```
横向向右闯关（跳跃 / 瞄准攻击）
  → 踩过的方块 4 秒后消失
  → 撞碎「字块」→ 获得那个字的效果（+ 副作用）
  → 踩怪头 → 踩死地怪 / 驯服飞怪载你飞
  → 打怪掉金币 → 进小屋/商店结构 → 花金币买补给
  → 失手掉下去 → 掉到下一层（可以按跳跃卸力免伤）
  → 死亡 → 结算魂币 → 重开
```

## 3. 主角：莫 ✔

| 属性 | 值 |
|---|---|
| 碰撞体 | 32×32 px（比格子小，避免卡缝） |
| 心 | 5 |
| 移速 | 250 px/s（加速度 2400 / 摩擦 2800） |
| 重力 / 最大下落 | 1500 / 950 |
| 跳跃初速 | −520 → **跳跃高度 90px ≈ 1.88 格** |
| 跳跃水平距离 | 约 173px ≈ **3.6 格** |
| 手感 | 土狼时间 0.10s + 输入缓冲 0.12s + 松手短跳 |

**变字**：撞碎字块后，主角字形真的会变成那个字（莫 + 日 → 暮）。✔

### 操作

| 键 | 动作 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| 空格 / W / ↑ / Z | 跳跃（落地前按下可卸力免掉落伤害） |
| **鼠标左键**（主）/ J / X | 攻击——**墨点朝鼠标方向射出** |
| Q / E | 主动技能 |

| R | 重开一局 |

> 攻击以鼠标为主：弹丸方向 = 主角指向鼠标的方向，可以朝上斜射。

## 4. 地面系统 ✔

### 4.1 方块三态

| 状态 | 视觉 | 规则 |
|---|---|---|
| 实心 | 深灰方框 | 可站立；莫触碰后进入 4 秒倒计时 |
| 倒计时中 | **变色 → 闪烁（越来越快）→ 缩小淡出** | 4 秒后消失 |
| 空 | 虚线方框残影 + 背景虚线网格 | 已归零 |

### 4.2 字块（核心改动）✔

**字不再飘在空气里，而是长成一块方砖。**

- 「字块」是一块**实心砖**，砖面显示它含的字（如「暮」），用该字的颜色描边。
- 莫**碰到它就把它撞碎**（0.25 秒碎裂动画 + 碎片飞散），碎掉的瞬间字的效果归莫所有。
- 站在地上走过去撞碎它 = 最自然的拾取方式；跳起来用头撞也可以。
- 因为它是实心的，撞碎之前会挡住去路 —— **"撞碎字块"本身就是通行的一部分**，不是额外的拾取动作。

### 4.3 世界是分层的 ✔

世界水平切成「层带」（每带 8 行），层带之间是空的，**向左/右/上/下都无限延伸**。
从洞里掉下去 = 落到下一层继续打，不是死。

### 4.4 掉落伤害（重做）✔

**穿关靠横向，掉下去是失误。** 掉落伤害的规则：

| 掉落高度 | 结果 |
|---|---|
| < **4.5 格** | 完全没事（普通起跳只有 1.88 格，永不触发） |
| 4.5 ~ **10 格** | 扣 **1 心**；但**落地前 0.22 秒内按下跳跃 → 卸力，0 伤害** |
| > 10 格 | 扣 **1 心**，且**无法卸力** |
| 任何情况 | **不会摔死**（永远剩至少 1 心） |

- 掉一层（8 格）正好落在"可以卸力"的区间 —— 失误有代价，但技术可以弥补。
- 危险下落时主角字体会变红闪烁，提示"该按跳跃了"。
- 成功卸力时弹出「卸力」提示。

## 5. 地形规则 ✔（横向为主）

| 参数 | 值 | 说明 |
|---|---|---|
| 层带高度 | 8 行 | 层与层的落差 |
| 平台块宽 | **11 列**（原 7） | 平台更长 → 横向连贯 |
| 台阶落差 | ≤ **1 格** | 必须 < 跳跃高度 90px，否则卡死 |
| 洞宽 | ≤ **3 格**，且偏向 1~2 格 | 必须 < 跳跃水平距离 173px |
| 开洞概率 | **35%**（原 55%） | 洞更少 → 掉落变成失误而不是常态 |
| 块两端留实地 | 各 ≥1 格 | 防止相邻块的洞拼成深渊 |
| 层带中部浮岛 | 15% | 掉下去的补救落脚点 |

> **目标是"横向连贯的走廊，偶尔有个坑"**，而不是"悬崖梯田"。

另外：**结构**（小屋等）会周期性嵌进地形，见第 9 章。

## 6. 偏旁系统 ✔

### 6.1 已实现的 6 个字

| 偏旁 | 字 | 类型 | 正面 | 副作用 |
|---|---|---|---|---|
| 心 | **慕** | 被动 | 磁吸：金币飞向你 | 敌人也被牵过来，移速 −8% |
| 日 | **暮** | 被动 | 地面消失变慢 40% | 视野变暗 |
| 饣 | **馍** | 立即 | 回 1 心 | — |
| 氵 | **漠** | 技能 Q | **三发水柱全部有效**，伤害并击退 | **无**（已移除副作用） |
| 土 | **墓** | 被动 | 踩过的方块不再消失 | 移速 −15% |
| 月 | **膜** | 被动 | 受伤 −40% | 移速 −10% |

槽位初始 2 个。所有数值因子相乘叠加。

### 6.2 偏旁 UI ✔

屏幕左下角是一排**字砖**（和世界里字块同一种视觉语言）——
每块砖显示当前携带的字，砖下面一行写它的效果与代价。
撞碎新字时，砖会"咔"地翻过来变成新字，并弹出「莫 + 日 = 暮」。

（不做弹窗三选一：**选择由"撞哪块砖"完成**，在平台跳跃里用位置做选择比弹窗更顺。）

### 6.3 可扩字（○）

| 偏旁 | 字 | 想法 |
|---|---|---|
| 力 | 募 | 召唤一个小莫帮你踩路（它也会踩掉你要站的地） |
| 巾 | 幕 | 短暂隐身（隐身时攻击失效） |
| 木 | 模 | 分身 |
| 虫 | 蟆 | 变形：跳更高 |
| 组合技 | 土+力 | 小莫踩出「墓碑」，成为永久落脚点 |

## 7. 怪物 ✔（重做）

**密度大幅下调**（原来太挤），分四种：

| 敌人 | 状态 | 行为 |
|---|---|---|
| **红色方块怪** | ✔ | 地面巡逻，遇墙/悬崖转身 |
| **猎手（寻人怪）** | ✔ | 地面**追着玩家跑**，会走过悬崖、撞墙就跳 —— 不再傻等 |
| **飞怪** | ✔ | 无重力飞行，平滑地追向玩家 |
| **红色偏旁怪** | ✔ | 稀有。碰到不掉血，而是**注入一个字的临时效果**——有正有负 |

### 7.1 踩头（关键手感）✔

| 情况 | 结果 |
|---|---|
| 从上方踩到**地怪**的头 | **踩死它**，主角弹起，**不掉血** |
| 从上方踩到**飞怪**的头 | 飞怪**不死**，被驯服 **6 秒**，载着主角朝主角朝向飞 —— 可以用它跨越长坑 |
| 侧面/下方碰到任何怪 | 掉 1 心（有 0.8 秒内置冷却） |

> 飞怪是**交通工具**，不是障碍：踩上去 = 上车。

### 7.2 红色偏旁怪的接触效果 ✔

碰到就消失，并给一个临时效果（正面/负面各半）：

| 红色字 | 效果 | 性质 |
|---|---|---|
| 心 | 回 1 心 | 正面 |
| 月 | 3 秒无敌 | 正面 |
| 日 | 5 秒内地面消失加速一倍 | 负面 |
| 土 | 脚下 5 格内的方块立刻碎裂 | 负面 |

刷怪率：方块怪 1.0% / 猎手 0.4% / 飞怪 0.5% / 红偏旁怪 0.2% / 字块 1.0%（每格平台）。
离主角 8 格内不刷。**出界的怪会被卸载**，所以不会越玩越卡。

## 8. 商店 ✔

- **商店是地形里的一种结构**（一个带顶棚的小摊），走过去按 **F** 打开。
- 用**局内金币**买：

| 商品 | 价格 | 效果 |
|---|---|---|
| 回心 | 2 金币 | 回 1 心 |
| 随机一个字 | 5 金币 | 直接获得一个随机字块的效果 |
| 加一个槽位 | 8 金币 | 槽位 +1（本局永久） |

## 9. 结构系统（像 MC 那样）✔

地形里会周期性嵌入**手工设计的小结构**，格式是一张字符网格（和 MC 的 schematics 一个思路）：

```
"....#...."     # = 实心方块
"..#####.."     W = 字块
".#######."     E = 巡逻怪   K = 猎手   F = 飞怪
"#..W.E..#"     R = 红偏旁怪 S = 商店
"........."     . = 空
```

**已内置 3 个结构**：

| 结构 | 样子 | 作用 |
|---|---|---|
| **小屋** | 尖顶、两侧立柱、地面层完全打通 | 屋里有字块和一只怪，跑过去就能吃到 |
| **小摊** | 立柱 + 顶棚 | 商店 |
| **悬字台** | 小顶棚 + 悬在 2 格高处的字块 | 站直够不到，**跳一下**才能撞到（跳跃高度 1.88 格） |

**设计约束（很重要）**：结构的地面层必须**左右贯通**——
玩家永远向右走，任何"死路"都是卡死。所有内置结构的底层整行都是空的。

生成方式：每隔 **34 列**一个「结构槽位」，55% 概率放一个结构；结构会把地基强制变实，
不会因为地形开洞而悬空。详见技术文档第 6 章。
