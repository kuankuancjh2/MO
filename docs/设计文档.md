# 《莫》游戏设计文档（GDD）

> 版本：v0.1（GameJam 概念版）
> 引擎：Godot 4.x
> 类型：横向闯关 + 轻肉鸽（程序拼装）+ 平台动作
> 主题：**莫**（"莫"字下面一个空，可填成 墓/慕/暮/募/幕/漠/膜…）

---

## 1. 一句话概念

你就是一个"莫"字。你踩过的一切都会化为虚无——用这份"没有"，闯过不断崩塌的世界，收集偏旁，把自己拼成新的字。

---

## 2. 主题与立意

**主题词解构**：`莫` = 一个空（下面的方块）。下面填不同的偏旁，变成不同的字、不同的人、不同的命运。

**核心立意（一句话能讲给评委听）**：

> "莫"是"没有"。但"没有"不是终点——踩过的地方会消失，而消失的地方，可以被你填成新的字、新的自己。**无中生有。**

设计上，我们把"莫=没有"这个语义，直接变成三条游戏规则：

1. **踩过的地方会消失**（"莫"触碰之处，皆归于无）——地面消耗机制。
2. **填上偏旁就变字**（"莫"不是终点，是未完成的自己）——变字/能力系统。
3. **"空"是资源也是危险**（虚线方块是未填的空白）——风险与机会并存。

---

## 3. 核心游戏循环（Game Loop）

```
移动/跳跃/攻击
    → 踩方块（方块进入消失倒计时）
    → 收集偏旁 → 变字 → 获得能力（立即/技能/被动）
    → 打怪（红色方块 / 红色偏旁字）→ 掉金币
    → 金币买技能（局内）/ 魂币买全局成长（局外）
    → 前进到关卡尽头 / 死亡
    → 死亡后保留魂币，解锁局外成长，重新开局
```

---

## 4. 主角：莫

- **形象**：一个"莫"字，用字体直接渲染（见美术章节）。
- **核心被动（身份机制）**：主角脚下的地面方块会进入消失倒计时。
- **基础能力**：左右移动、跳跃、攻击。

| 属性 | 初始值 | 说明 |
|---|---|---|
| 移动速度 | 适中 | 可被全局成长提升 |
| 跳跃 | 1 段 | 可解锁 2 段跳（全局） |
| 攻击 | 近战/短距 | 见第 7 章 |
| 地面消失倒计时 | 4.0s（可调） | 核心手感参数 |

> **关键手感原则**：消失倒计时必须**全程可视化**（颜色渐变 → 闪烁 → 虚化），玩家必须能"读"出方块还剩多久。这是本作第一重要的手感。

---

## 5. 地面系统（核心机制）

### 5.1 方块的三态

| 状态 | 视觉 | 规则 |
|---|---|---|
| **实心方块** | 实线方框 + 填充色 | 可站立；被主角踩上后进入消失倒计时 |
| **倒计时中** | 颜色渐变 → 闪烁 → 虚化 | 正在消失，倒计时结束消失 |
| **空白（空）** | **虚线正方形** | 已经是"没有"；不可站立，掉下去即落入深渊 |

> 虚线正方形是贯穿全作的核心视觉符号——它是"尚未被填的字底"，也是"已经消失的虚空"。同一个图形，既是机会（可以填）也是危险（会掉下去）。

### 5.2 死亡判定（方案 B）

- 掉入**空白/深渊** = 死亡。
- 普通方块消失后**可以跳跃通过/跳过**（方案 B：能跳 + 不能回头）。
- 即：地面是"一次性消耗品"，逼迫玩家持续向右移动，不能折返。

### 5.3 消失倒计时参数

- 默认 **4.0 秒**。
- 设计上做成**可全局成长**（更高阶的局外技能可以延长/缩短，见第 9 章）。
- 建议难度来源之一：后期关卡通过"更短倒计时"提升紧张感，而非单纯加怪。

---

## 6. 偏旁系统（变字 = 能力）

### 6.1 组字表（莫 + 偏旁）

> 偏旁**不局限于"莫"下面**。我们按"位置"分类，位置本身也能暗示能力倾向。

| 偏旁 | 位置 | 组成字 | 能力方向（示意） |
|---|---|---|---|
| 心 ⺗ | 下 | **慕** | 情感 / 吸引 / 牵绊 |
| 日 | 下 | **暮** | 时间 / 光影 / 黑暗 |
| 力 | 下 | **募** | 招募 / 召唤 |
| 土 | 下 | **墓** | 死亡 / 埋葬 / 重压 |
| 巾 | 下 | **幕** | 遮蔽 / 隐藏 / 掩护 |
| 氵 | 左 | **漠** | 水 / 流动 / 冲刷 |
| 月 | 左 | **膜** | 保护 / 膜 / 格挡 |
| 木 | 左 | **模** | 模板 / 复制 / 分身 |
| 饣 | 左 | **馍** | 食物 / 恢复 |
| 虫 | 左 | **蟆** | 变形 / 跳跃增强（蟾蜍） |

> 这张表是**无限扩展**的——这是本作最大的延展性：每一个能跟"莫"组字的偏旁，都可以变成一个能力。GameJam 阶段先实现其中 4~6 个，其余留作扩展。

### 6.2 三类成字效果

每个"字"的能力，明确属于以下三类之一：

| 类型 | 触发方式 | 例子 |
|---|---|---|
| **立即（Instant）** | 拿到即触发一次 | 馍：立即回血；募：立即召唤一个小莫 |
| **技能（Active）** | 占用一个技能键，按 Q/E 释放，有 CD | 漠：冲刷前方，冲走敌人；幕：短暂隐身/无敌 |
| **被动（Passive）** | 常驻，只要携带就生效 | 暮：你的消失倒计时变慢；膜：每 N 秒挡一次伤害 |

### 6.3 副作用（每个字都有代价）

**每个变字都有副作用**——这是你拍板的核心，也是深度来源。示例：

| 字 | 正面效果 | 副作用 |
|---|---|---|
| 慕 | 吸引金币/道具飞向你 | 也会吸引敌人靠近你 |
| 暮 | 你的消失倒计时变慢 30% | 屏幕变暗，视野缩小 |
| 募 | 召唤小莫帮你踩掉危险方块 | 小莫踩过的方块消失得更快，且可能踩掉你要站的路 |
| 墓 | 踩到的方块立刻化为坚实地砖（永不消失） | 你移动变慢（负重） |
| 幕 | 短暂隐身，敌人不攻击 | 隐身期间你的攻击也失效 |
| 漠 | 技能冲刷前方 | 使用后你下方地面会额外融化一段 |
| 膜 | 每 N 秒挡一次伤害 | 挡完后短暂护甲破碎，受伤 +20% |

> **设计原则**：副作用不是惩罚，而是**选择**。让玩家在"要能力"和"承受代价"之间博弈。基础字（前期掉落的）代价轻、正面强；高阶字代价重、上限高。

### 6.4 多偏旁组合（槽位系统）

- 主角有 **偏旁槽位**（初始 2 个，可全局成长到 3~4 个）。
- 携带多个偏旁 = 同时持有多个字/能力，**效果叠加**。
- 某些组合触发 **组合技（Synergy）**，例如：

| 组合 | 触发效果 |
|---|---|
| 心 + 日（慕 + 暮） | "暮慕"：黑暗中吸引之物发光，视野补正 |
| 土 + 力（墓 + 募） | 召唤的小莫踩出"墓碑"，墓碑成为永久落脚点 |
| 氵 + 日（漠 + 暮） | "暮色沙漠"：冲刷技能附带减速区域 |

> 组合技是肉鸽深度的核心，也是本作与"单纯平台跳跃"拉开差距的地方。GameJam 阶段先做 2~3 组组合技。

## 7. 怪物系统

### 7.1 敌人视觉语言

- **普通怪**：**红色实心方块**（与玩家地面的"可站方块"形成颜色区分：可站方块是中性/冷色，敌人是红色）。
- **特殊怪（少数）**：**红色的偏旁或红色字**（如一个红色的"日"、红色的"慕"）——精英/稀有怪。

### 7.2 敌人行为

| 敌人 | 表现 | 规则 |
|---|---|---|
| 红色方块（普通） | 巡逻/冲向玩家 | 触碰玩家 → 扣血 |
| 红色偏旁 / 红字（特殊） | 更少出现，行为特殊 | 触碰玩家 → **产生特殊效果** |

### 7.3 特殊怪的"接触效果"（关键：有正有负）

**特殊怪（红偏旁/红字）触碰玩家后，不是单纯扣血，而是注入一个"字的效果"**——有时是正面，有时是负面：

| 特殊怪 | 触碰效果 | 性质 |
|---|---|---|
| 红"心" | 接下来 N 秒你的攻击吸血 | 正面 |
| 红"日" | 你的消失倒计时瞬间缩短一半 | 负面 |
| 红"力" | 召唤一个敌对小莫 | 负面 |
| 红"土" | 你脚下方块立刻消失 | 负面 |
| 红"月" | 给你一层护盾 | 正面 |

> **设计意图**：让"接触"变得不可预测、需要判断——看到红偏旁怪，玩家要权衡"主动撞它赌正面 buff"还是"躲开"。这是把"接触"从纯惩罚升级成**风险决策**。

### 7.4 攻击系统（带攻击）

- 主角有基础攻击（近战短距，或发射"墨点/笔画"投射物，见美术风格）。
- 攻击能**击杀普通红色方块怪**，掉落金币。
- 特殊怪血量更高，可能掉落偏旁 / 更多金币 / 魂币。

## 8. 关卡（程序拼装，向右闯关）

- 关卡是**横向向右**的线性推进。
- 采用**程序拼装（Chunk-based）**而非完全随机：把若干**手调段落（chunk/room）**按规则随机拼接。
  - 每个 chunk 是一段已经验证过可通行的地形（含方块、偏旁、敌人、空白）。
  - 拼接时保证**衔接处高度可通行**、难度递增。
  - 好处：手感可控（不会出现纯随机那种"过不去/恶心"的地形），又有每局不同。
- 关卡分**若干小段**，每段末尾一个**偏旁宝箱**（可替换当前槽位的一个偏旁），关卡尽头是**出口/门**。

### 8.1 Chunk 类型

| Chunk | 内容 |
|---|---|
| 平地跑 | 连续方块，少量空白跳跃 |
| 缺口跳 | 一段空白深渊 + 需要跳跃通过 |
| 偏旁房 | 放置一个偏旁 + 少量怪 |
| 怪物房 | 密集红色方块怪 + 一个特殊怪 |
| 崩坏段 | 消失倒计时极短的方块段，纯跑酷 |

---

## 9. 全局成长 / 商店（双货币）

### 9.1 双货币

| 货币 | 获取 | 用途 | 是否跨局 |
|---|---|---|---|
| **金币** | 局内打怪掉落 | 局内商店买当局技能 | 否（死亡清空） |
| **魂币** | 死亡时按进度结算 + 特殊怪掉落 | 局外买全局成长 | 是（永久） |

### 9.2 局内商店（金币）

- 关卡内出现商店节点，用金币购买**当局临时技能/偏旁/回血**。

### 9.3 全局成长（魂币，分两级）

| 层级 | 性质 | 例子 |
|---|---|---|
| **基础技能** | 纯好处，无副作用 | +移速、+攻击力、+初始血量、2 段跳、+槽位数、延长消失倒计时 |
| **高阶技能** | 有好处**也有坏处**（tradeoff） | 大幅+攻击 但 消失倒计时更短；+槽位 但 移速变慢；2 段跳 但 受伤害 +20% |

> **设计意图**：基础层让玩家有稳定的成长正反馈；高阶层制造 build 选择的博弈，配合偏旁副作用，形成本作"build 多样性"的第二层。

## 10. 操作（键位建议）

| 键 | 动作 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| Space | 跳跃 |
| J 或 鼠标左键 | 攻击 |
| Q / E | 技能键（释放携带的 Active 字的能力） |
| （预留） | 交互（商店/宝箱） |

---

## 11. 难度曲线

1. **前 1~2 段**：只教学"踩→消失→跳"，无怪或极少怪。
2. **中段**：引入红方块怪 + 1 个偏旁，让玩家体验"变字"。
3. **后段**：特殊怪（红偏旁）出现，倒计时缩短，引入组合技。
4. **Boss/出口**：用一段"崩坏段"（极短倒计时跑酷）作为关卡高潮。

## 12. 美术 / 音频风格

### 12.1 视觉（字体渲染为主）

- **主角**：一个"莫"字（大字号，黑/深色，带轻微描边）。
- **偏旁**：单个偏旁字符（心、日、力…）。
- **方块**：程序绘制的方框（实线 = 可站，虚线 = 空）。
- **敌人**：红色渲染的方块/偏旁/字。
- **整体**：极简黑白 + 主题强调色（红色=危险，虚=灰），契合汉字/书法质感。

### 12.2 资产可替换（重要，详见技术文档）

所有视觉元素（字体、颜色、方块线型、字）都必须走**统一资产层**，支持**不改代码换美术**（换字体、换配色、换贴图）。这是硬性要求，技术文档专列一章。

### 12.3 音频

- 音效：跳跃、方块消失（碎/化）、变字（墨水音）、受击、金币。
- 配乐：留白 + 极简，契合"无/空"的主题（可选）。

## 13. GameJam 范围裁剪（MVP 优先级）

**P0（必须）**：
- 主角移动/跳跃/攻击 + 地面消失倒计时（可视化）+ 掉深渊死亡
- 2 个偏旁（如 心→慕、日→暮）+ 三类效果各 1 个
- 红方块普通怪 + 金币 + 局内商店
- 程序拼装关卡（3~4 种 chunk）

**P1（应有）**：
- 特殊怪（红偏旁，正负效果）
- 偏旁槽位 + 1~2 组组合技
- 魂币 + 全局成长（基础/高阶各 3~4 个）

**P2（时间够再做）**：
- 更多偏旁字（漠/膜/墓/募…）
- Boss 段 / 崩坏跑酷高潮段
- 音效配乐打磨

---

## 14. 未来扩展方向

- 更多"莫+X"字，每个字一个能力。
- 组合技扩展成"偏旁网络"。
- Boss 用"复合字"（如"模""蟆"）做精英/首领。
- 双人/本地合作：两个莫字互相踩，协作填字。
