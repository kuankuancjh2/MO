# 《莫》游戏设计文档（GDD）

> 引擎：Godot 4.7（GDScript） · 类型：横向闯关 + 平台动作 + 轻肉鸽
> 状态：**可玩原型已跑通**（本文档标注 ✔ 的是已实现，○ 的是待做）

---

## 1. 一句话概念

你就是一个「莫」字。你踩过的一切都会化为虚无——用这份「没有」闯过不断崩塌的世界，
捡起偏旁，把自己拼成新的字。

## 2. 主题与立意

`莫` = 一个空。下面填不同偏旁，就成了不同的字、不同的人。

> 「莫」是「没有」。但「没有」不是终点——踩过的地方会消失，而消失的地方可以被你填成新的字。
> **无中生有。**

三条规则直接来自这个语义：

1. **踩过的地方会消失** —— 地面耗尽机制 ✔
2. **填上偏旁就变成新的字** —— 变字/能力系统 ✔
3. **「空」是资源也是危险** —— 虚线空位既是失去的路，也是可以填的位置 ✔

---

## 3. 核心循环

```
向右移动 / 跳跃 / 攻击
  → 踩过的方块进入 4 秒消失倒计时（变色 → 闪烁 → 消散）
  → 捡偏旁 → 变成新的字 → 获得能力（立即 / 技能 / 被动）+ 副作用
  → 打红色方块怪 → 掉金币
  → 失足掉落 → 掉到下一层继续打（少量掉落伤害，摔不死）
  → 死亡 → 结算魂币 → 重开，用魂币买全局成长
```

---

## 4. 主角：莫

- 字形用字体直接渲染（换字体只改 `assets/config/asset_config.tres`）。
- **身份机制**：他触碰过的方块会开始消失倒计时。
- **变字**：携带偏旁后，主角字形真的会变成那个字（莫 + 日 → 暮）。✔

| 属性 | 值 | 说明 |
|---|---|---|
| 碰撞体 | 32×32 px | 比格子（48px）小，避免卡在格子缝上 |
| 心 | 5 | 全局成长可 +1/级 |
| 移动速度 | 250 px/s | |
| 加速度 / 摩擦 | 2400 / 2800 | |
| 重力 / 最大下落 | 1500 / 950 | |
| 跳跃初速 | −520 | **跳跃高度 90px ≈ 1.88 格** |
| 跳跃水平距离 | 约 173px ≈ 3.6 格 | 由高度和重力推出，是地形设计的硬约束 |
| 跳助手感 | 土狼时间 0.10s + 输入缓冲 0.12s + 松手短跳 | 手感细节，别删 |

### 操作

| 键 | 动作 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| 空格 / W / ↑ / Z | 跳跃 |
| J / X / 鼠标左键 | 攻击（发射墨点） |
| Q / E | 释放主动技能（携带对应偏旁时） |
| R | 重开一局 |

## 5. 地面系统 ✔

### 5.1 方块的三态

| 状态 | 视觉 | 规则 |
|---|---|---|
| 实心 | 深灰方框 | 可站立；被莫触碰后进入倒计时 |
| 倒计时中 | **变色 → 闪烁 → 缩小淡出**（三段） | 4 秒后消失 |
| 空 | **虚线正方形残影 + 背景虚线网格** | 已归零；掉下去 = 落到下一层 |

**消失动画的三段占比（4.0 秒内）**：
- 前 60%（0~2.4s）：颜色从深灰渐变到「被踩」的土黄。
- 中 30%（2.4~3.6s）：颜色转向危险红，**闪烁频率越来越快**。
- 后 10%（3.6~4.0s）：缩小 40% + 淡出，原地留下虚线方框残影。

> 这条是本作第一重要的手感：**玩家必须能"读"出他还剩多久**。闪得越快 = 越危险。

### 5.2 世界是分层的（任意方向延伸）✔

世界被水平切成「层带」，每带 8 行；层带之间是空的。

```
层带 0   ████████░░░███████░░░░███     <- 平台 + 洞，玩家在上面跑
         （空的 6 行）
层带 -1  ░░████████░░██████░░░██
         （空的 6 行）
层带 -2  ...
```

- 向左右无限延伸，上下也无限套层。
- 从洞里掉下去 = **落到下一层继续打**，不是死。
- 关卡是一条「不断往下漏的无限阶梯」。

### 5.3 掉落伤害 ✔（按你的要求：仅长距离、量少、上限低）

| 参数 | 值 |
|---|---|
| 起算阈值 | 掉落超过 **4.5 格** 才开始受伤 |
| 伤害 | 超出部分每格 **0.3 心** |
| 单次上限 | **1.5 心** |
| 是否致死 | **否** —— 掉落伤害永远给你留至少 1 心 |

- 普通起跳最高 1.88 格，**永远不会**触发掉落伤害。
- 一层一层往下掉（8 格）吃约 1.05 心，是「有点疼但不致命」的节奏。
- 掉到更下面一层时，HUD 会提示「第 N 层」。

## 6. 地形生成规则 ✔（以及为什么必须这么约束）

生成器把每 7 列分成一个「块」，块内平台高度统一，块与块之间落差最多 1 格；
每个块最多开 1 个洞，洞宽 1~3 格，且**块的两端永远留实地**。

| 约束 | 值 | 为什么 |
|---|---|---|
| 台阶最大落差 | **1 格 = 48px** | 必须 < 跳跃高度 90px，否则跳不上去 = 卡死 |
| 洞最大宽度 | **3 格 = 144px** | 必须 < 跳跃水平距离 173px，否则跳不过去 = 卡死 |
| 相邻块的洞之间 | 至少隔 2 格实地 | 防止两个洞拼成 6 格深渊 |

> **这三条是硬约束，改地形一定要重跑测试。** 冒烟测试里有专门的断言守着它们
> （`devtools/smoke_test.gd` 的第 1 节）。

另外层带中间会飘一些浮岛（22% 概率，宽 2 格），作为落脚点和节奏变化。

## 7. 偏旁系统 ✔

### 7.1 已实现的 6 个字

| 偏旁 | 字 | 类型 | 正面效果 | 副作用 |
|---|---|---|---|---|
| 心 ⺗ | **慕** | 被动 | 磁吸：金币飞向你 | 敌人也会被牵过来，移速 −8% |
| 日 | **暮** | 被动 | 地面消失变慢 40% | 天变黑，视野变暗 |
| 饣 | **馍** | 立即 | 拾取时回 1 心 | — |
| 氵 | **漠** | 技能(Q) | 喷水柱，伤害并击退前方敌人 | 用完后 3 秒内地面消失加速 |
| 土 | **墓** | 被动 | 踩过的方块不再消失（化为碑） | 负重：移速 −15% |
| 月 | **膜** | 被动 | 受伤 −40% | 移速 −10% |

- **槽位**：初始 2 个（全局成长可加）。满了会替换掉最后一个。
- **多偏旁叠加**：所有数值因子相乘；字形显示最近吸收的那个字。

### 7.2 三类效果的分工（新增偏旁时按这个判断）

| 类型 | 写法 | 例子 |
|---|---|---|
| **被动 / 立即（纯数值）** | **只改 `.tres` 数据**，不写代码 | 暮、墓、膜、馍 |
| **需要额外逻辑** | 在 `scripts/systems/radical_effects.gd` 加一个分支 | 漠（喷水柱 + 限时副作用） |

> 大部分偏旁应该只改数据。一个偏旁如果非得写代码才能实现，先想想能不能用数值因子表达。

### 7.3 扩展空间（○ 未实现）

这个框架天然可以无限扩字，位置本身就能暗示能力倾向：

| 偏旁 | 字 | 想做的能力 |
|---|---|---|
| 力 | 募 | 召唤一个小莫帮你踩路（代价：它也踩掉你要站的地） |
| 巾 | 幕 | 短暂隐身/无敌（代价：隐身时攻击失效） |
| 木 | 模 | 分身：留下一个复制体 |
| 虫 | 蟆 | 变形成蟾蜍：跳得更高 |
| 组合技（○） | 心+日 | 「暮慕」：黑暗中吸引之物发光，视野补正 |
| 组合技（○） | 土+力 | 召唤的小莫踩出「墓碑」，成为永久落脚点 |

## 8. 怪物 ✔（部分）

| 敌人 | 状态 | 行为 |
|---|---|---|
| **红色方块怪** | ✔ | 巡逻（遇墙/悬崖转身），碰到主角扣 1 心，被打死掉 1~3 金币 |
| **红色偏旁怪** | ○ | 稀有怪。触碰主角不扣血，而是**注入一个字的效果**——有时正面（红「心」→吸血）、有时负面（红「日」→倒计时瞬间缩短一半） |

> 红偏旁的用意：让「接触」从纯惩罚变成**风险决策**——要不要主动撞上去赌一个正面 buff。

数值：HP 2、接触伤害 1、移速 68、接触冷却 0.8s。每格平台有 4.5% 概率刷怪、1.2% 概率刷偏旁。

## 9. 双货币与成长

| 货币 | 获取 | 用途 | 跨局 | 状态 |
|---|---|---|---|---|
| **金币** | 打怪掉落 | 局内商店 | 否 | 金币 ✔ / 商店 ○ |
| **魂币** | 死亡结算（3 + 金币/2） | 局外全局成长 | 是 | 结算+存档 ✔ / 商店 ○ |

**全局成长两级**（数据与存档已就绪，商店 UI ○）：

| 层级 | 性质 | 例子 |
|---|---|---|
| 基础 | 纯好处 | +移速、+心、+槽位、延长消失倒计时 |
| 高阶 | 有好处也有坏处 | 大幅加攻击但消失更快 |

存档位置：`user://mo_save.json`（自动保存，含魂币、已购升级、最深纪录）。

## 10. 美术方向

- **主角**：一个「莫」字（大字号，浅色）。
- **偏旁**：单个偏旁字符（心 / 日 / 氵…），带光晕。
- **方块**：程序绘制的方框；实线 = 可站，虚线 = 空。
- **敌人**：红色渲染的方块。
- **整体**：极简暗色 + 红线（危险）+ 虚线（空），契合汉字/书法质感。

> **换美术不需要改代码。** 全部走 `assets/config/asset_config.tres` 一个文件
> （字体、每种元素的颜色、方块贴图）。详见技术文档第 8 章。
