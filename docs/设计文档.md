# 《莫》游戏设计文档（GDD）

> 引擎：Godot 4.7 · 类型：横向闯关（岛屿）+ 平台动作 + 轻肉鸽
> 状态：✔ 已实现 ○ 待做

---

## 1. 一句话概念

你就是一个「莫」字。你踩过的一切都会化为虚无。踩碎的地里会浮出偏旁，
把它们拼成新的字——用这份「没有」,闯过一座又一座正在崩塌的岛。

`莫` = 一个空。填「心」是**慕**，填「日」是**暮**，填「氵」是**漠**。

> **无中生有。** —— 而有个东西叫「有」，它专门和你作对（见第 10 章）。

---

## 2. 核心循环

```
横向闯过一座座岛（跳跃 / 瞄准攻击）
  → 踩过的方块碎裂（变色 → 闪烁 → 消散，2.6 秒）
  → 碎开的方块里浮出偏旁 → 偏旁飞向你 → 变字
  → 踩到怪头上 = 骑着它走（不杀、不掉血）
  → 打怪掉金币 → 小屋/集市里花金币买补给
  → 失手掉进断崖 → 落到下一层（落地前按跳跃可以卸力免伤）
  → 遭遇「有之殿」→ 打 Boss「有」
  → 死亡 → 结算魂币 → 重开
```

## 3. 主角：莫 ✔

| 属性 | 值 |
|---|---|
| 碰撞体 | 32×32 px |
| 心 | 5 |
| 移速 | 250 px/s（加速度 2400 / 摩擦 2800） |
| 重力 / 最大下落 | 1500 / 950 |
| 跳跃初速 | −520 → **跳跃高度 90px ≈ 1.88 格** |
| 跳跃水平距离 | 约 173px ≈ **3.6 格** |
| 手感 | 土狼时间 0.10s + 输入缓冲 0.12s + 松手短跳 |

**变字**：拿到字之后主角字形真的会变成那个字（莫 + 日 → 暮）。

**二段跳**：是**永久特性**（拿到「蟆」一次就写进存档，之后每局都能用）。

### 操作

| 键 | 动作 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| 空格 / W / ↑ / Z | 跳跃（落地前按下可卸力；有二段跳时空中再按一次） |
| **鼠标左键**（主）/ J / X | 攻击——墨点朝鼠标方向射出 |

## 4. 地面系统 ✔

### 4.1 方块三态

| 状态 | 视觉 | 规则 |
|---|---|---|
| 实心 | 岩石（厚，岛体）/ 木板（薄，桥） | 莫触碰后进入 **2.6 秒**倒计时 |
| 倒计时中 | 变色 → 闪烁（越来越快）→ 缩小淡出 | |
| 空 | 虚线方框残影 + 背景虚线网格 | 已归零 |

> 2.6 秒是"逼你往前走"的核心数值。觉得太急可以在 `data/balance.tres` 里调。

### 4.2 ★ 偏旁藏在方块里 ✔

**偏旁不是浮在空中的道具，而是埋在地面方块里。**

- 某些地表方块的砖面上有一个**微弱的彩色光点** —— 那是"这里可能有东西"的提示（不保证）。
- 莫踩上去，方块照常碎裂；**碎开的那一瞬间，偏旁从碎块里浮出来**。
- 浮出的偏旁会**自己飞向莫**（不会因为跑太快而错过），碰到就吸收。
- 被「谟」强化时，藏字的砖会**明显发亮**，一眼就能挑出来。

> 于是"踩过的地面会崩塌"这件事有了回报：**你在废墟里捡字**。

### 4.3 世界是分层的 ✔

水平切成「层带」（每带 8 行），层带之间是空的，**向左/右/上/下都无限延伸**。
掉进断崖 = 落到下一层继续打。

### 4.4 掉落伤害与卸力 ✔

| 掉落高度 | 结果 |
|---|---|
| < **4.5 格** | 完全没事（普通起跳只有 1.88 格，永不触发） |
| 4.5 ~ **10 格** | 扣 **1 心**；**落地前 0.22 秒内按下跳跃 → 卸力，0 伤害** |
| > 10 格 | 扣 **1 心**，**无法卸力** |
| 任何情况 | **不会摔死**（永远剩至少 1 心） |

危险下落时主角字体会变红闪烁，提示"该按跳跃了"。

## 5. ★ 地图：岛屿 + 横向桥接 ✔

### 5.1 算法（查过资料后选的方案）

参考的做法是「**噪声切岛 + 只连接相邻岛的桥**」（不做寻路）——
把地图分成 **play area（岛）** 和 **connector（桥）** 两类，这是平台游戏最省事又最可控的路子。

1. 每层带用 **1D fBm 值噪声**算一条"陆地场"，超过阈值就是陆地。
   连续的陆地列 = **一座岛**；岛与岛之间是缺口。
2. **每座岛内部高度恒定**（岛内没有需要跳的台阶）。
3. 岛与岛之间架**桥**（细木板）：缺口 ≤ 16 格且两边高度差爬得上去就架。
4. 架不了桥的缺口 = **断崖**：故意留的深渊，掉下去到下一层。

### 5.2 两条硬约束（测试会守）

| 约束 | 理由 |
|---|---|
| 相邻落脚点落差 ≤ **1 格** | 2 格 = 96px > 跳跃高度 90px，会卡死 |
| **缺口要么 ≤3 格（跳得过去），要么 ≥8 格（明显是断崖）** | 不允许"看着能跳其实跳不过去"的暧昧缺口 |

> 这条"不能暧昧"是靠 **岛高度只做 2 档**（0/1）来保证的：相邻岛落差 ≤1，
> 于是任何 ≤16 格的缺口都架得起桥，剩下的必然是宽断崖。

### 5.3 实测表现

连续扫描 800 列：**岛屿 12~19 座**、桥 30~45 列、**横向连贯度 75%~89%**、
没有暧昧缺口、落差恒 ≤1 格。

## 6. 偏旁系统 ✔

### 6.1 已实现的 11 个字

| 偏旁 | 字 | 类型 | 正面 | 副作用 |
|---|---|---|---|---|
| 心 | **慕** | 被动 | 磁吸：金币/偏旁飞向你 | 敌人也被牵过来，移速 −8% |
| 日 | **暮** | 被动 | 地面消失变慢 40% | 视野变暗 |
| 饣 | **馍** | 立即 | 回 1 心 | — |
| 氵 | **漠** | 技能 Q | 三发水柱全部有效，伤害并击退 | 无 |
| 土 | **墓** | 被动 | 踩过的方块不再消失 | 移速 −15% |
| 月 | **膜** | 被动 | 受伤 −40% | 移速 −10% |
| 虫 | **蟆** | 被动 | 跳更高 + **永久解锁二段跳** | 无 |
| 扌 | **摸** | 技能 E | 把附近的金币和偏旁一把抓过来 | 无 |
| 艹 | **蘑** | 被动 | 拾取回 1 心，每 18 秒自动回 1 心 | 移速 −5% |
| 讠 | **谟** | 被动 | 看见藏起来的字 + 地面消失更慢 | 无 |
| 钅 | **镆** | 被动 | 攻击力 +80% | 出招更慢（冷却 +35%） |

槽位初始 2 个。所有数值因子相乘叠加。

### 6.2 ★ 组合技 ✔

同时带着特定的几个字就会触发（不看顺序），凑齐时弹提示：

| 组合 | 名字 | 效果 |
|---|---|---|
| 心 + 日 | **暮慕** | 黑暗中吸来的东西会发光：视野补正 + 磁吸范围 ×1.6 |
| 氵 + 日 | **暮沙** | 水柱从三发变**五发**，且使用后回 1 心 |
| 土 + 力 | **碑林** | 碑立得住你了：移速惩罚取消 |
| 虫 + 日 | **暮蝉** | 跳跃力度 +25% |
| 钅 + 土 | **重剑** | 攻击力 +50%，且墨点能打碎方块 |
| 心 + 扌 | **慕摸** | 伸手一摸什么都吸得过来：攻击力 +40% |

### 6.3 偏旁 UI ✔

屏幕左下角是一排**字砖**（和地面上的砖同一种视觉语言），空槽画成虚线方块，
砖下面写清它当前的效果与代价。

**不做弹窗三选一**：选择由"踩哪块地"完成——字埋在方块里，你在废墟里捡到什么就是什么。

## 7. ★ 怪物 ✔

### 7.1 四种敌人

| 敌人 | 行为 | 可骑 |
|---|---|---|
| **红色方块怪** | 地面巡逻，遇墙/悬崖转身 | ✔ |
| **猎手** | 地面**追着你跑**，撞墙会跳，会走下悬崖 | ✔ |
| **飞怪** | 无重力**正弦巡航**（水平往返 + 上下起伏），极其缓慢地朝你挪动 | ✔ |
| **红色偏旁怪** | 漂浮，慢慢飘向你，**不能被骑** | ✘ |

### 7.2 ★ 踩怪 = 骑着走（不杀、不死、不掉血）✔

**踩到任何怪的头上都不会杀死它，也不会掉血 —— 你会站在它身上被它带着走。**

- 就像骑在一个**无法控制**的东西上：它往哪走，你就到哪（想下来就跳走）。
- 地怪会继续巡逻/追你，飞怪会继续巡航 —— 你只是搭了个便车。
- **侧面**碰到怪才会掉 1 心（0.8 秒内置冷却）。
- 所以怪既是威胁，也是**交通工具**：踩着飞怪跨过断崖，或者踩着猎手被它带着冲一段。

> 不做"驯服提示"：玩家踩到普通怪头上自然会发现能站住，也会自然想到踩飞怪。

### 7.3 红色偏旁怪：接触 = 赌一把 ✔

碰到就消失，并给一个临时效果（正面/负面各半）：

| 红色字 | 效果 | 性质 |
|---|---|---|
| 心 | 回 1 心 | 正面 |
| 月 | 3 秒无敌 | 正面 |
| 日 | 5 秒内地面消失加速一倍 | 负面 |
| 土 | 脚下 5 格内的方块立刻碎裂 | 负面 |

刷怪率（每格平台）：方块怪 1.0% / 猎手 0.4% / 飞怪 0.5% / 红偏旁怪 0.6% / 字块 1.8%。
离主角 8 格内不刷。出界的怪会被卸载。

## 8. 商店 ✔

- 商店是地形里的一种结构（带顶棚的小摊或集市），走过去按 **F** 打开。
- **界面故意不做全屏遮罩**：面板挂在**右上角**，主角和脚下一直看得见 ——
  因为买东西的时候时间没有停，你脚下的方块还在倒计时。
  面板里还写着一行「时间不会停 —— 你脚下的方块还在塌」。

| 商品 | 价格 | 效果 |
|---|---|---|
| 回心 | 2 金币 | 回 1 心 |
| 随机一个字 | 5 金币 | 立刻获得一个随机字 |
| 加一个槽位 | 8 金币 | 槽位 +1（本局限一次） |

## 9. 结构系统（像 MC 那样）✔

地形里周期性嵌入**手工设计的小结构**，格式是一张字符网格：

```
"....#...."     # = 实心方块
"..#####.."     W = 藏了偏旁的方块    S = 商店
".#######."     E/K/F/R = 巡逻怪/猎手/飞怪/红偏旁怪
"#..W.E..#"     B = Boss「有」
"........."     . = 空
```

**已内置 8 个结构**：

| 结构 | 作用 |
|---|---|
| **小屋** | 尖顶，屋里有藏字的方块和一只怪 |
| **小摊** | 一个商店 |
| **集市** | 两个商店 |
| **悬字台** | 字块悬在 2 格高处，跳一下才能撞到 |
| **拱门** | 可穿过的门洞 |
| **柱廊** | 一排柱子（纯装饰节奏） |
| **碑** | 小柱子里嵌一个字 |
| **有之殿** | **Boss「有」的殿堂**（见第 10 章） |

**唯一硬性约束：结构的"地面层"必须左右贯通**——玩家只向右走，死路 = 卡死。
生成器会在生成时自检，不合法的结构会被跳过并报警告（这条自检已经抓到过我自己写错的结构）。

## 10. ★ Boss「有」 ✔

**剧情立意**：莫 = 无；有 = 有。
莫走到哪里就把一切抹成虚无，「有」则不停地**造东西**——造地面、造小怪、吐字攻击。
你要一边躲开它造出来的东西，一边把它自己抹掉。

- 走进「有之殿」并在 420px 内 → 它出现（**一旦开打就不会随镜头卸载**）。
- 血量 20，掉一半后进入狂暴（出招更快）。
- 三种招式轮换：
  1. **造物**：在你脚下凭空造出一排方块（可以踩，但也会挡路；莫碰过照样会消失）
  2. **招募**：召唤两只小怪
  3. **吐字**：朝你打出三发红色投射物
- 击杀后：大碎裂 + 掉 8 枚金币 + **40 魂币**，并提示「你抹掉了「有」—— 但「莫」还在」。
- HUD 顶部有它的血条。
