# 《莫》技术文档（TDD）

> 版本：v0.1
> 引擎：Godot 4.x（GDScript）
> 关联文档：`docs/设计文档.md`

---

## 1. 技术栈与约定

- **引擎**：Godot 4.x（稳定版，如 4.2/4.3），GDScript。
- **渲染**：2D。主角/偏旁/敌人全部用 **Label（字体）** 渲染；方块用程序绘制（见第 8 章资产层）。
- **数据驱动**：偏旁、怪物、技能、chunk 全部用**资源文件**（`.tres` Resource 或 `.json`）定义，逻辑代码只读数据。
- **命名**：节点 PascalCase，脚本 snake_case 文件名 + class_name，变量 snake_case，常量 UPPER。

## 4. 数据驱动设计（核心 Resource 类）

### 4.1 `radical_data.gd`（偏旁/字定义）

```gdscript
class_name RadicalData extends Resource

enum EffectType { INSTANT, ACTIVE, PASSIVE }

@export var id: String              # 唯一 id，如 "mu_xin"
@export var base_char: String = "莫" # 主角字
@export var radical_char: String    # 偏旁字，如 "心" "日"
@export var composed_char: String   # 组成字，如 "慕" "暮"
@export var radical_position: String # "bottom" / "left"（决定视觉摆放）
@export var effect_type: EffectType
@export var display_name: String
@export var description: String     # 正面效果描述
@export var downside: String        # 副作用描述（面向 UI）
# 数值字段（副作用与正收益都在这里，可空）
@export var vanish_slow_factor: float = 0.0   # 消失倒计时倍率（>1 变慢）
@export var move_speed_factor: float = 1.0
@export var damage_taken_factor: float = 1.0
@export var attract_factor: float = 0.0        # 慕：吸引
@export var vision_scale: float = 1.0          # 暮：视野
@export var summon: PackedScene               # 募：召唤物场景
@export var skill_key: String = ""            # "Q"/"E"，Active 用
@export var cooldown: float = 0.0             # Active 用
@export var synergy_group: String = ""        # 组合技分组
```

> **原则**：副作用不单独写"坏"字段，而是直接用可负的数值因子（如 `vanish_slow_factor` 可 <1 变成缩短）。这样同一套字段既能描述正收益也能描述副作用，逻辑统一。

### 4.2 `enemy_data.gd`（敌人定义）

```gdscript
class_name EnemyData extends Resource

@export var id: String
@export var is_radical_enemy: bool          # 是否特殊怪（红偏旁/字）
@export var glyph: String = "■"             # 普通怪用方块字形；特殊怪用偏旁/字
@export var hp: float = 1.0
@export var contact_damage: float = 1.0     # 普通怪触碰扣血
@export var contact_effect_id: String = ""  # 特殊怪触碰效果（引用 touch_effect 定义）
@export var contact_effect_sign: int = 0    # +1 正面 / -1 负面 / 0 中性
@export var drops: Dictionary = {}          # {"coins": n, "souls": n, "radical": id}
```

### 4.3 `skill_data.gd` / `chunk_data.gd`（技能 / 关卡段落）

- `skill_data.gd`：局内技能 + 全局成长（含 `is_meta`、`has_tradeoff`、正面/负面数值对）。
- `chunk_data.gd`：一个 chunk 的地形描述，用**紧凑字符串或 PackedScene** 表示（见 6 章）。

## 5. 各系统实现要点

### 5.1 地面消失系统（`solid_tile.gd` + `vanish.gdshader`）

- `SolidTile` 是 `StaticBody2D`（或 Area2D 检测踩踏）。
- 玩家踩上 → 启动 `Timer(4.0s)`（可被玩家因子缩放）→ 触发消失动画 → `queue_free()`。
- **可视化**分三段，用 Tween + Shader 参数：
  1. 前 60%：颜色从正常 → 变红/变暗（`modulate` 渐变）。
  2. 后 30%：闪烁（`visible` 交替，频率递增）。
  3. 最后 10%：虚化/消散（shader 的 `dissolve` 值 0→1，方块碎片/淡出）。
- 消失的时长参数全部来自玩家的 `RadicalSlots` 聚合因子（暮字等会修改 `vanish_slow_factor`）。

### 5.2 偏旁槽位与组合（`radical_slots.gd`）

- 维护 `Array[RadicalData]`，上限来自全局成长（初始 2）。
- **聚合**：每帧或状态变化时，把所有携带偏旁的数值因子乘算/加算成玩家的最终属性（移速、倒计时倍率、受伤倍率、视野等）。
- **组合技**：检测当前偏旁的 `synergy_group` 集合，命中预定义组合则叠加额外效果（组合技表也做成数据）。

### 5.3 攻击（`player_attack.gd`）

- 攻击发射"笔画/墨点"投射物（`Area2D`），或近战判定框。
- 命中红方块怪 → 扣敌人 hp → 死亡掉落金币。

### 5.4 敌人接触效果（`touch_effect.gd`）

- 特殊怪（红偏旁）与玩家 Area 重叠 → 查询 `contact_effect_id` → 应用正/负效果（改玩家临时状态：吸血、倒计时缩短、召唤敌对小莫、脚下方块消失、给护盾）。
- 用**一个通用的"临时状态修改器"系统**，效果表数据化，避免为每个效果写死代码。

### 5.5 关卡拼装（`level_builder.gd`）

- `ChunkData` 描述一段地形（用字符串网格，如 `"###__##"`，`#`=实心方块、`_`=空白、`R`=偏旁、`E`=敌人）。
- LevelBuilder 按规则从 chunk 池随机抽选拼接，保证：
  - 衔接高度差 ≤ 可跳高度。
  - 难度随段数递增（早期 chunk 池无特殊怪，后期加入崩坏段）。
  - 每 N 段放一个偏旁宝箱，末尾放出口。
- 种子化随机（`RandomNumberGenerator` + seed），便于复现与调试。

### 5.6 双货币与持久化（`run_state.gd` / `meta_state.gd` / `save_manager.gd`）

- `run_state.gd`：当局金币、血量、携带偏旁（死亡清空）。
- `meta_state.gd`：魂币、已购全局成长（持久化）。
- `save_manager.gd`：用 `user://save.json` 或 `ConfigFile` 存局外状态。

## 6. 关卡 chunk 的数据格式（字符串网格）

推荐用**紧凑字符串**表示一个 chunk，易读、易手调：

```
chunk 示例（10 行高，向右延伸）：
"__________"
"__________"
"__________"
"###__####"    # 可站方块
"_______###"
"#R###E####"    # R=偏旁，E=敌人
```

- 解析时逐字符生成对应节点（`#`→SolidTile、`_`→VoidTile、`R`→RadicalPickup、`E`→敌人）。
- 手调 chunk 存在 `data/chunks/` 下，`ChunkData` 引用网格 + 元信息（难度、可出现的段位）。

## 7. 着色器（`vanish.gdshader`）

方块消失用 shader 的 `dissolve` 参数做"碎片/虚化"效果（噪声边缘 + alpha 淡出），配合 modulate 颜色渐变。顶点/片段着色器都保持简单，避免性能压力。

```gdshader
shader_type canvas_item;
uniform float dissolve : hint_range(0.0, 1.0) = 0.0;
// 用噪声让边缘碎裂，dissolve 增大时 alpha 下降、像素被"抹去"
```

## 8. ★ 资产替换方案（美术可整体更换，不改代码）

这是硬性要求。核心思想：**代码只引用语义 id，不引用具体贴图/字体/颜色；所有具体资产通过一个 `asset_config.tres` 统一映射。**

### 8.1 `asset_config.tres`（唯一改美术的入口）

```gdscript
# scripts/systems/asset_loader.gd 读取这个 Resource
@export var main_font: FontFile            # 主字体
@export var color_player: Color            # 主角"莫"字颜色
@export var color_radical: Color           # 偏旁颜色
@export var color_enemy: Color             # 敌人（红）颜色
@export var color_solid_tile: Color        # 可站方块
@export var color_void_tile: Color         # 空白/深渊
@export var color_vanish_warn: Color       # 消失警告色
@export var solid_tile_style: TileStyle    # 方块线型（实线/贴图）
@export var void_tile_style: TileStyle     # 虚线/贴图
```

- 所有 `Label`（莫字、偏旁、敌人字）统一用 `main_font` + 对应 color。
- 所有方块统一用 `*_tile_style`，如果换成贴图，方块节点从"程序画线"切换为"Sprite 贴图"——但**节点接口不变**（都暴露 `set_style()`），内部实现可变。

### 8.2 字体资源说明（CJK 支持）

- Godot 需要**显式加载支持中文的字体**才能渲染"莫/慕/暮"等字。
- 默认方案：内置/引用一款开源 CJK 字体（如 Noto Sans SC / Source Han Sans），放在 `assets/fonts/main_font.ttf`。
- 也可用系统字体 `SystemFont`，但导出 Web/跨平台时**推荐打包字体文件**避免缺字。

### 8.3 替换流程（给美术/后续开发者）

1. 换字体 → 替换 `assets/fonts/main_font.ttf`。
2. 换配色 → 改 `asset_config.tres` 里的颜色字段。
3. 换方块 → 替换 `solid_tile_style`/`void_tile_style` 的贴图或线型。
4. 换音效 → 替换 `assets/audio/*`，命名保持一致。
5. **不触碰任何 `.gd` 脚本**。

> 额外建议：把 `asset_config.tres` 挂到一个 **autoload 单例 `Assets`**，全项目通过 `Assets.cfg.xxx` 访问，进一步解耦。

## 10. 关键参数表（集中管理）

所有手感/平衡数值集中到一个 `data/balance.tres`（`BalanceData` Resource），方便调参：

| 参数 | 默认 | 说明 |
|---|---|---|
| `vanish_time_base` | 4.0s | 消失倒计时基准 |
| `jump_velocity` | — | 跳跃力度（按像素调） |
| `move_speed` | — | 移动速度 |
| `attack_cooldown` | — | 攻击间隔 |

| `coin_drop_range` | [1,3] | 怪掉金币范围 |

## 11. 性能与注意事项

- 方块消失用 `queue_free()` 及时释放；同屏方块数量可控（chunk 是手调小段）。
- 大量 `Label` 渲染：合并同类颜色到一个 CanvasItem 或用 `LabelSettings` 减少 draw call；必要时给 TileLayer 用批处理。
- 字体渲染中文性能开销低，可放心用 Label 作主角/偏旁。
- 组合技/聚合计算放在"状态变化"时缓存，避免每帧重算。

## 12. 开发顺序建议（对应 GDD 的 P0→P2）

1. 工程初始化 + Assets 资产层 + Balance 参数表。
2. 主角移动/跳跃/攻击 + 地面消失倒计时（含可视化 shader）。
3. 偏旁数据 + 槽位 + 2 个字的三种效果。
4. 红方块怪 + 金币 + 局内商店。
5. chunk 拼装关卡。
6. 特殊怪（正负接触效果）→ 魂币 + 全局成长 → 组合技。
