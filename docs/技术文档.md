## 4. 数据驱动

### 4.1 `RadicalData`（一个字）

```
id / radical_char / composed_char / radical_position
effect_type               # INSTANT 0 / ACTIVE 1 / PASSIVE 2
description / downside     # 给玩家看的文案
── 数值因子（1.0 = 无影响；正面与副作用共用同一套字段）──
vanish_slow_factor         >1 地面消失更慢
move_factor / damage_taken_factor / vision_factor
attack_factor / attack_cooldown_factor / jump_factor
attract / heal_on_pickup / regen_period
── 永久特性 ──
unlocks_trait              # "double_jump" → 写进存档，之后每局都生效
── 主动技能 ──
skill_action / cooldown
```

### 4.2 `StructureData`（一个结构）

`grid: PackedStringArray`。**最后一行对齐"玩家身体行"**（平台顶上面那一格），往上依次 -2、-3…

| 字符 | 含义 |
|---|---|
| `#` | 实心 |
| `W` | **藏了偏旁的方块**（`is_solid` 视它为实心） |
| `E`/`K`/`F`/`R` | 巡逻怪 / 猎手 / 飞怪 / 红偏旁怪 |
| `B` | Boss「有」 |
| `S` | 商店 |

⚠️ **地面层（最后一行）必须左右贯通**。`StructureLibrary.usable_list()` 会自检并跳过不合法的结构。

### 4.3 新增内容

- **加字**：`gen_resources.gd` 的 `defs` 加一行 → 删 `data/radicals/*.tres` 与 `radical_library.tres` → 重跑生成器。纯数值效果不用写代码。
- **加结构**：`struct_defs` 加一张网格即可。
- **加组合技**：`scripts/systems/synergies.gd` 的 `LIST` 加一行（`req` + 效果开关）。

## 5. ★ 地形：岛屿 + 横向桥接（`terrain_gen.gd`）

### 5.1 算法

```
1D fBm 值噪声（3 倍频）→ 阈值 → 连续的陆地列 = 一座岛
每座岛内部高度恒定（2 档：0 / 1）
相邻岛之间：缺口 ≤ MAX_BRIDGE_GAP(16) 且高度差爬得上去 → 架桥（细木板，1 格厚）
架不了 → 断崖（故意留的深渊，掉下去到下一层）
```

`is_solid(cx, cy, seed)` 是**纯函数** → 地块可以随便卸载重载。
但**列信息有缓存**（按列算一次，而不是按格算），否则每格都做噪声+扫描会卡：

```gdscript
static var _col_cache: Dictionary    # Vector2i(cx,k) -> Vector3i(kind, surface_row, island_start)
static func column(cx, k, s) -> Vector3i
```

`kind`：0 = 天空（无地面）/ 1 = 岛 / 2 = 桥。

### 5.2 两条硬约束（回归测试守着）

| 约束 | 依据 |
|---|---|
| 相邻落脚点落差 ≤ 1 格 (48px) | < 跳跃高度 90px |
| 缺口 ≤ 3 格（跳得过去）**或** ≥ 8 格（明显断崖），不允许中间值 | 跳跃水平距离 173px = 3.6 格 |

第二条靠 **岛高度只做 2 档** 保证：相邻岛落差 ≤1 → 任何 ≤16 格的缺口都架得起桥 →
剩下的必然是宽断崖，不存在"看着能跳其实跳不过去"的死点。

### 5.3 加载 / 卸载

`GameWorld._process` 检测主角移动超 3 格就重建 `±24 列 × ±18 行`，并**同时卸载出界的
方块和实体**。实体按"出生格"字典去重；方块与字块用 `_destroyed` 记住永久消失。

## 6. 方块 / 字块 / 偏旁

### 6.1 `SolidTile`

两种外观：`style 0 = 岩石`（岛体，厚）/ `style 1 = 木板`（桥，薄，碰撞体只有 14px 高）。

倒计时 = `Balance.d.vanish_time × player.vanish_factor`。三段可视化：变色 → 闪烁 → 消散。

**性能**：`_ready` 里 `set_process(false)`，被碰到才 `set_process(true)`。

### 6.2 ★ 偏旁藏在地面方块里

```
SolidTile.radical != null  →  碎掉时 new RadicalPickup（从碎块里浮出）
RadicalPickup              →  先向上飘 0.35s，再自动飞向主角，碰到即吸收
```

- 判断某格是否藏字：`TerrainGen.has_radical(cx, cy, seed)`（结构 `W` 或地表砖按概率）。
- 砖面上画一个微弱彩色光点作为提示；带「谟」时提示更亮更大。
- 所以"偏旁会飞向玩家"是刻意的：免得玩家跑太快错过，永不白捡。

### 6.3 视觉可替换

`SolidTile` 优先用 `assets/art/tile_rock.png` / `tile_rock_stepped.png` / `tile_bridge.png`，
没有就程序画。

## 7. 怪物

### 7.1 主角与怪的接口（约定同名方法，主角不需要知道具体类型）

| 方法 / 属性 | 说明 |
|---|---|
| `try_contact_damage(player)` | 侧面撞到主角 → 按内置冷却扣血 |
| `hit(damage, knockback)` | 被投射物打中 |
| `rideable` | 站到它头上时是"骑着走"还是照常触发接触效果 |
| `move_delta` | 这一帧的位移（骑乘用） |

### 7.2 ★ 踩怪 = 骑着走

主角在 `_touch_bodies()` 里遍历 `move_and_slide()` 的碰撞：

```gdscript
if can_ride and normal.y < -0.5 and pre_vel.y > -1.0:
    riding = collider          # 骑上去：不杀它、不掉血
else:
    collider.try_contact_damage(self)
```

然后在 `_apply_ride()` 里把怪的水平位移补给主角：

```gdscript
global_position.x += riding.move_delta.x     # 只补水平
```

**只补水平**：竖直方向交给物理（碰撞会把主角顶起来、重力会让他跟着落下），
否则会重复计算、人在怪背上一跳一跳的。

每个敌人每帧记录 `move_delta = global_position - _prev_pos`（`_prev_pos` 在 `move_and_slide` 前后取）。

### 7.3 飞怪 / 红偏旁怪：必须用 `CharacterBody2D`

**踩过的坑**：这两类最早用 `AnimatableBody2D`，结果是"既不飞也不动"。原因有两个：
`AnimatableBody2D` 继承自 `StaticBody2D`；而且 `sync_to_physics = true` 时物理服务器会覆盖
直接写入的 `position`。改成 `CharacterBody2D` + `velocity` + `move_and_slide()` 后一切正常。

飞怪的巡航：水平正弦往返 + 上下正弦起伏，同时把巡逻中心**极缓慢**地挪向玩家
（所以玩家等得到它、跳得上去，它又不会贴脸把人顶来顶去）。

### 7.4 Boss「有」

- `ENGAGE_DIST = 420`：进入范围才交战；**交战后 `_unload` 不卸载它**。
- 招式轮换：造物（`GameWorld.spawn_temp_tile`）/ 招募小怪 / 三发红色投射物。
- 血掉一半进入狂暴。死亡给金币 + 40 魂币 + 提示语。
- HUD 顶部有血条（HUD 每帧从 `group("boss")` 里找）。

## 8. ★ 换美术（放文件即生效，不改代码）

### 8.1 三步

| 想改什么 | 做法 |
|---|---|
| 换图 | 把图丢进 `assets/art/`，文件名见 `docs/美术资源指南.md`（如 `player.png`、`tile_rock.png`） |
| 换配色 / 字体 | 改 `assets/config/asset_config.tres` |
| 换音效 | 把音频丢进 `assets/audio/`，文件名见 `assets/audio/README.md` |

代码里统一走：

```gdscript
Assets.get_art("player")            # 找不到返回 null → 走程序绘制的占位图
Assets.get_frames("player_run")     # player_run_01.png / _02 / _03… 有几张返回几张
Assets.cfg.color_enemy              # 配色
Assets.font                         # 字体
```

启动时会打印「已加载 N 个美术资源（assets/art/）」，给美工确认用。

### 8.2 动画

统一约定：`<名字>_01.png`、`_02`… 从 01 开始不跳号，`get_frames()` 自动收集。
主角已按状态机选帧（待机/跑/跳/落/攻击/骑），敌人也行。详见美术资源指南第 2 节。

## 10. 性能（"玩久了越来越卡"的根因与修复）

### 10.1 根因

`GameWorld._refresh` 只卸载方块，**敌人/字块/商店从来没被卸载**（字典只增不减）。
于是玩家一路向右，身后留下一串永不释放的怪 → 节点数线性增长 → 越来越卡。
**重开一局就恢复**（整个场景被重建）——这是泄漏的典型特征。

### 10.2 修复

| 修复 | 说明 |
|---|---|
| 卸载矩形外的实体 | 遍历 `_spawned` 出界的 `queue_free` + `erase` |
| 实体按出生格去重 | `_spawned` 的 key 保持为出生格（不能挪），否则会重复刷怪 |
| 消耗即销号 | 怪被打死 / 字块被撞碎 → `consume_cell(self)` 把出生格写进 `_destroyed`，否则原地无限重生 |
| 砖块默认关 `_process` | 被踩才开 |
| 敌人只在状态变化时重绘 | 不再每帧 `queue_redraw()` |
| 背景只在相机移动时重绘 | 记录上次相机格坐标 |
| 地形列信息缓存 | 按列算一次，不是按格算 |

### 10.3 回归测试

第 11 节：连走 600 格后**实体数与节点数必须有界**。修复前会线性增长。

## 11. 踩过的坑（别再踩）

### 11.1 物理体必须"入树前"定位

```gdscript
player.position = spawn; add_child(player)     # ✓
add_child(player); player.global_position = spawn   # ✗ 会以 (0,0) 注册 → 被解穿透弹飞 419px
```

### 11.2 不能用 `node is StaticBody2D` 判断"要不要帮它设位置"

`AnimatableBody2D` 也继承自 `StaticBody2D`，会把飞怪/红偏旁怪一起跳过 → 它们全堆在 (0,0)，
表现是"主角一出生就被弹上天"。要按具体类型判断。

### 11.3 哨兵值 `-1` 不能用 `< 0` 判断 ⚠️

```gdscript
if left == -1 or right == -1:      # ✓
if left < 0 or right < 0:          # ✗ 列坐标本身就是负数！
```

这个 bug 让**原点左侧的所有缺口都判定成"找不到岛"、一律不架桥** ——
表现为"桥很少、而且左边会出现跳不过去的死缺口"。查了半天才定位到。

### 11.4 不能在碰撞回调里往场景树加物理体

报 `Can't change this state while flushing queries`。用 `parent.call_deferred("add_child", node)`。

### 11.5 `move_and_slide()` 会回写 `velocity`

Godot 4 把"实际位移 / delta"写回 `velocity`。看到莫名的大速度，先怀疑解穿透。

### 11.6 地形 / 结构的可通过性

- 第一版地形每列随机起伏 0~2 格 → 2 格台阶 = 96px > 跳跃高度 90px → 走两步就卡死。
- 结构同理：四面封死的小屋就是死路。生成器已加自检。
- 岛屿高度只做 2 档，原因见 5.2。
- **改地形/加结构后一定重跑冒烟测试。**

### 11.7 冒烟测试自己的坑

- 主角长时间待在世界里时**可能被怪打死**，之后所有断言都在尸体上跑（`heal()` 对死人是 return）。
- `_invuln`（受击无敌 0.35s）会让连续伤害断言静默失效 → 测试里直接清零再断言。
- 扫面带状统计时，**扫描区间两端会截断**，要把边缘的缺口排除，否则会误报。
- 「N 格空档」实际只掉 `N - 0.83` 格（中心从 +24 落到"实心顶 -16"），
  想测"掉 5 格以上"要找 6 格空。
