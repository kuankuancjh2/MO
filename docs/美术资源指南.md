# 《莫》美术资源指南（给美工看）

> 核心原则：**放文件就生效，不用改代码。**
> 把图片按下面的**固定文件名**丢进 `assets/art/`，游戏下次启动就会用它。
> 找不到就用程序画占位图（现在能玩的就是占位图）。

---

## 1. 通用规则

| 项 | 约定 |
|---|---|
| 目录 | `assets/art/` |
| 格式 | `.png`（推荐，支持透明）/ `.jpg` / `.webp` |
| 命名 | 见第 3 节的表，必须**一字不差** |
| 像素尺寸 | 见每个资源后面标注的建议尺寸，可以更大（会自动缩放） |
| 透明背景 | 推荐。角色、敌人、字块都要透明底 |
| 风格 | 极简、暗色背景上要能看清。参考色：危险=红 #e23b3b，空=白/灰虚线，金=#ffd23b |
| 线条 | 如果有描边，描边不要太细（游戏里有暗色叠加，太细会糊） |

**坐标系**：所有图片默认按「中心对齐」绘制。所以画的时候把主体放在画布正中间。

---

## 2. 动画怎么做（先只做最少的）

### 2.1 推荐做法：序列帧 + 固定命名

同一动作画成多张，用 `_01 _02 _03…` 结尾，游戏会自动按顺序播放：

```
assets/art/player_run_01.png
assets/art/player_run_02.png
assets/art/player_run_03.png
assets/art/player_run_04.png
```

有 `_01`…`_NN` 就自动变成动画（帧率默认 8 帧/秒，可在 `asset_config.tres` 调）。
只放一张（如 `player_jump.png`）就是静态图。

### 2.2 现在**只需要**画这些（先做最少）

| 动作 | 需要几张 | 说明 |
|---|---|---|
| 待机 | 1~2 张 | 站着 |
| 跑动 | 4 张 | 循环 |
| 跳跃/下落 | 各 1 张 | |
| 攻击 | 2 张 | 挥手/吐字 |
| 方块破碎 | 3 张 | 从完整→裂开→碎 |

**先不加更多动画。** 上面的画完，游戏的观感就会完全变样。剩下的（受击、变字、被驯服、boss…）以后按同一套命名规则加即可。

### 2.3 不想画序列帧怎么办

也可以只画**一张**当静态图，游戏照样能跑（帧数=1）。这比画得难看的多帧更好。

## 3. 资源清单（文件名必须完全一致）

### 3.1 主角

| 文件名 | 建议尺寸 | 说明 |
|---|---|---|
| `player.png` | 48×48 | 主角。默认是「莫」字。如果画成小人，注意这是**可替换**的 |
| `player_idle_01.png` | 48×48 | 待机 |
| `player_run_01..04.png` | 48×48 | 跑动 4 帧 |
| `player_jump.png` | 48×48 | 上升 |
| `player_fall.png` | 48×48 | 下落 |
| `player_attack_01..02.png` | 48×48 | 攻击 |
| `player_ride.png` | 48×48 | 骑在怪身上（可选） |

> 主角字形本身会随携带的字变化（莫→暮→漠…）。如果画成小人，这个变化就没了 ——
> 建议**主角画成"墨迹/剪影"**，让字浮在上面（游戏支持两者叠加），这样既有个性又保留变字。

### 3.2 地形

| 文件名 | 建议尺寸 | 说明 |
|---|---|---|
| `tile_rock.png` | 48×48 | 普通地面方块（岛上） |
| `tile_rock_stepped.png` | 48×48 | 被踩过、正在消失的方块 |
| `tile_bridge.png` | 48×16 | **桥**（细木板），会按 48 宽平铺 |
| `tile_void.png` | 48×48 | 「空」的虚线方框（可选，不填就用程序画的虚线） |

### 3.3 敌人

| 文件名 | 建议尺寸 | 说明 |
|---|---|---|
| `enemy_block.png` | 36×36 | 红方块怪（巡逻） |
| `enemy_seeker.png` | 36×36 | 猎手（追你） |
| `enemy_flyer.png` | 48×34 | 飞怪。**注意：它是可以踩上去骑的**，造型要能站人（宽一点、上面平） |
| `enemy_radical.png` | 40×40 | 红偏旁怪（碰到给正/负效果） |
| `boss_you.png` | 120×120 | Boss「有」 |

### 3.4 道具与 UI

| 文件名 | 建议尺寸 | 说明 |
|---|---|---|
| `coin.png` | 20×20 | 金币 |
| `radical_glow.png` | 44×44 | 偏旁掉出来时的光晕（偏旁字本身用字体渲染） |
| `shop.png` | 48×48 | 商店摊位 |
| `hud_slot.png` | 34×34 | 偏旁 UI 的字砖底 |

### 3.5 每个偏旁单独替换（可选）

如果某个字想要专属图形，用 `radical_<id>.png`：

```
assets/art/radical_mo_ri.png      对应 id = mo_ri（暮）
assets/art/radical_mo_shui.png    对应 id = mo_shui（漠）
```

id 列表见 `data/radicals/*.tres` 的文件名。

## 4. 音频（另外放在 `assets/audio/`）

见 `assets/audio/README.md`。文件名：`jump / land / vanish / stomp / shatter / transform / hit / coin`。

---

## 5. 换配色（不用画图）

想只调颜色不画图：改 `assets/config/asset_config.tres` 里的 `color_*` 字段。

---

## 6. 交付检查清单

- [ ] 文件名和上面表格**完全一致**（大小写敏感）
- [ ] 放在 `assets/art/` 下（不是子目录）
- [ ] PNG 带透明通道
- [ ] 主体居中
- [ ] 序列帧用 `_01 _02 _03` 结尾，从 01 开始，不跳号
- [ ] 先跑一次游戏确认生效（`Tools/Godot.exe`，F5）

有拿不准的尺寸，就按建议尺寸的**整数倍**画（比如 2 倍），游戏会自动缩放。
